# Article Editorial Guidance

Use this reference for long-form opinion, analysis, transcript commentary, or sourced essays.

## Article Shape

- Start with the scene or core tension, not a list of findings.
- Give readers enough context to understand the source event without having consumed it.
- Build the argument through connected paragraphs. Avoid "first side / second side / verdict" blocks when the user asks for article flow.
- Use headings as chapter breaks, not as cards.
- End with a conclusion that answers the governing question. Do not merely summarize.

## Truth And Argument

- Distinguish what a source directly states from what follows by inference.
- Steelman opposing arguments before judging them.
- Use "right", "wrong", "insufficient", and "true but incomplete" when the evidence supports that precision.
- Do not use post-truth framing unless the user asks for it. Narrative can help readers care, but the article should still test claims against reality.

## Sources

- Use primary sources for the main factual claims: transcript, official blog, official policy document, paper, dataset, or product page.
- Use commentary sources only for public reception, tone, or secondary interpretation.
- Keep source lists concise. If the article is for the web, source lists usually belong at the end unless the user asks for a top source block.
- Do not overquote. Prefer paraphrase and link.

## Revision Discipline

- Treat user comments as editorial direction. Preserve what the user praised.
- When the user names exact text to change, search for it and edit only the relevant passage.
- When the user asks for a new versioned page, base it on the latest accepted live version unless they specify another source.
