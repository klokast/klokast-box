`build-alpine-seed.sh` builds the Alpine-specific diskless seed bundle (`boot/` and `apks/<arch>/`) needed later by the Ansible playbook `ansible/playbooks/12-bootstrap-diskless-build.yml` to install Alpine dom0 on the mini PC.

The "Alpine seed" is the set of files that Ansible playbooks will place onto the SSD, for Alpine to boot from.

- Output directory: `ansible/artifacts/alpine-seed/`
- Output shape: `alpine-standard-<release>-<arch>.tar.gz`
- Trigger: initial boot of the mini-pc.
- Inputs: the generated Debian ISO is generic and not secret-bearing.

The Alpine seed tarball is not involved in Tailscale enrollment. Bootstrap
identity is entered later in the Debian live onboarding portal:

- node name: for example `duh`
- Tailscale auth key: a `tskey-auth-*` generated by a tailnet
  Owner/Admin/Network admin that can assign `tag:bootstrap`
- portal command: `tailscale up --ssh --hostname=<node>-bootstrap
  --advertise-tags=tag:bootstrap --auth-key=<key>`
- Tailscale ACL: tailscale-ssh access from the deployment server (`tag:ops`)
  to the bootstrap Debian live system (`tag:bootstrap`) as user `root`
